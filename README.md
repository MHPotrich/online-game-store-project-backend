# Online Game Store Project Backend

## Requirements
- Docker
- Java

## Setup

- build container command: ```docker compose up```
- pgadmin server config:

	- Host Name/Address: ```host.docker.internal```

## Routes

### Users
- Get - `/users`
- Post - `/users`
- Get - `/users/<user-id>`
### Games
- Get - `/games`
- Post - `/games`
- Get - `/games/<game-id>`
